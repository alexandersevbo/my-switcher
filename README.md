# my-switcher

Крошечная программа для Windows: выделяете текст, набранный не в той раскладке, дважды нажимаете **левый Shift** — и `ghbdtn` превращается в `привет`.

Только ручное исправление по команде. Никакого автопереключения, слежки за набором и телеметрии; в сеть программа обращается только по кнопке «Проверить обновления». Один exe на 27 КБ, установка в один клик, исходники — несколько небольших файлов, которые легко прочитать самому.

*English: a tiny Windows tray utility that converts selected text between Russian (ЙЦУКЕН) and English (QWERTY) keyboard layouts, or fixes accidental CapsLock, when you double-tap Left Shift. No automatic switching, no logging; network is used only when you click "check for updates".*

## Скачать

Последняя версия — на странице [Releases](../../releases/latest): файл `MySwitcher.exe`.

Работает на Windows 10 и 11 без установки дополнительных компонентов (использует встроенный в Windows .NET Framework 4.8).

## Установка

1. Запустите `MySwitcher.exe` откуда угодно — из «Загрузок», с флешки.
2. На вопрос «Установить my-switcher на этот компьютер?» ответьте **Да**.

Программа скопируется в `%LOCALAPPDATA%\Programs\MySwitcher`, появится в меню «Пуск» как *my-switcher*, добавится в автозапуск и сразу запустится — в трее появится иконка «Aя». Права администратора не нужны. Ответ **Нет** — запуск без установки.

Exe не подписан, поэтому Windows SmartScreen может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».

**Обновление:** иконка в трее → **Проверить обновления…**. Если на GitHub есть новая версия, программа предложит обновиться, скачает её и перезапустится. (В версии 1.1.0 этого пункта нет — её обновить вручную: трей → Выход, запустить новый exe, ответить «Да».)

**Удаление:** иконка в трее → **Удалить с компьютера…** — убирает автозапуск, ярлык и файлы.

## Как пользоваться

1. Выделите неправильно набранный текст.
2. Дважды нажмите и отпустите левый Shift.

| Было | Стало |
|---|---|
| `ghbdtn? rfr ltkf&` | `привет, как дела?` — и раскладка окна переключается на русскую |
| `руддщ цщкдв` | `hello world` — и раскладка переключается на английскую |
| `пРИВЕТ` при включённом CapsLock | `Привет`, CapsLock выключается |
| `пРИВЕТ` (CapsLock уже выключен) | `Привет` |

После исправления текст остаётся выделенным, поэтому:
- повторный двойной Shift вернёт как было;
- текст, набранный и в капсе, и в чужой раскладке (`gHBDTN`), исправляется двумя двойными Shift: сначала регистр, потом раскладка.

Направление определяется по тексту: больше кириллицы — переводим в английскую раскладку, больше латиницы — в русскую. Знаки препинания переводятся по тем же клавишам, что и буквы. Если букв нет совсем, решает текущая раскладка окна.

Двойной Shift засчитывается, только если между нажатиями не было других клавиш и оба нажатия короткие — поэтому выделение через Shift+стрелки его не вызывает.

## Меню в трее

- **Включено** — временно отключить (или двойной клик по иконке; иконка станет серой).
- **Запускать при входе в Windows** — автозапуск вкл/выкл.
- **Проверить обновления…** — показывает текущую версию, сверяет её с последним релизом на GitHub.
- **Удалить с компьютера…** — есть только у установленной копии.
- **Выход**.

## Ограничения

- Текст передаётся через буфер обмена (Ctrl+C → исправление → Ctrl+V); прежнее содержимое буфера затем возвращается.
- Нужно именно выделение. Некоторые редакторы (например, VS Code) без выделения копируют всю строку — тогда исправленная строка вставится у курсора.
- В консоли Ctrl+C прерывает программу — там не использовать.
- Не работает в окнах, запущенных от администратора, если сам my-switcher запущен без прав администратора (ограничение Windows).
- Поддерживаются только русская и английская раскладки.

## Конфиденциальность

Чтобы поймать двойной Shift, программа ставит низкоуровневый хук клавиатуры ([`src/DoubleShiftHook.cs`](src/DoubleShiftHook.cs)). Хук не запоминает нажатия: он отслеживает только левый Shift, а любая другая клавиша лишь сбрасывает счётчик. Сетевой код один — [`src/Updater.cs`](src/Updater.cs): он срабатывает только по нажатию «Проверить обновления», запрашивает у `api.github.com` номер последнего релиза и при вашем согласии скачивает exe с `github.com`. Больше никаких обращений в сеть нет, ничего не отправляется. На диск программа пишет только при установке, обновлении и удалении (копия exe, ярлык, ключ автозапуска в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).

## Сборка из исходников

Нужен [.NET SDK](https://dotnet.microsoft.com/download) (любой современный; проект собирается под .NET Framework 4.8).

```bash
dotnet build -c Release
```

Результат — `bin\Release\net48\MySwitcher.exe`, это весь дистрибутив (`.config` и `.pdb` рядом не нужны).

### Выпуск релиза

Релиз собирается на GitHub автоматически при отправке тега вида `vX.Y.Z` ([`.github/workflows/release.yml`](.github/workflows/release.yml)):

```bash
git tag v1.2.0
git push origin v1.2.0
```

Перед этим обязательно поднять `<Version>` в `MySwitcher.csproj` до того же номера: по нему программа понимает, что обновление новее.

| [`src/SelectionFixer.cs`](src/SelectionFixer.cs) | копирует выделение, исправляет, вставляет, возвращает буфер |
| [`src/TextConverter.cs`](src/TextConverter.cs) | таблицы ЙЦУКЕН ↔ QWERTY и инверсия регистра |
| [`src/Keyboard.cs`](src/Keyboard.cs) | синтетические нажатия и переключение раскладки |
| [`src/TrayContext.cs`](src/TrayContext.cs) | иконка и меню в трее |
| [`src/Installer.cs`](src/Installer.cs) | самоустановка, автозапуск, ярлык, удаление |
| [`src/Updater.cs`](src/Updater.cs), [`src/GitHubRelease.cs`](src/GitHubRelease.cs) | проверка и установка обновлений с GitHub |
