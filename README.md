# my-switcher

Минимальная замена Punto Switcher: только ручное исправление выделенного текста по двойному нажатию **левого Shift**. Никакого автопереключения, сети, логов и настроек в файлах. Весь код — несколько файлов в `src/`.

## Как пользоваться

1. Выделить неправильно набранный текст.
2. Дважды нажать и отпустить левый Shift.

Что произойдёт:

| Ситуация | Результат |
|---|---|
| `ghbdtn? rfr ltkf&` | `привет, как дела?` (и раскладка окна → русская) |
| `руддщ цщкдв` | `hello world` (и раскладка окна → английская) |
| Включён CapsLock, текст `пРИВЕТ` | `Привет`, CapsLock выключается |
| CapsLock уже выключен, но в тексте есть слово вида `пРИВЕТ` | `Привет` |

После исправления текст снова выделен (если он в одну строку и не длиннее 300 символов), поэтому:
- повторный двойной Shift вернёт как было;
- если текст набран и в капсе, и в чужой раскладке (`gHBDTN`), первый двойной Shift исправит регистр, второй — раскладку.

Направление выбирается по тексту: больше кириллицы — переводим в английскую, больше латиницы — в русскую. Если букв нет (только знаки), решает текущая раскладка окна.

Двойной Shift засчитывается, только если между нажатиями не было других клавиш и каждое нажатие короткое — выделение через Shift+стрелки его не вызывает.

## Установка на другой компьютер

Достаточно передать один файл `dist\MySwitcher.exe` (≈27 КБ, работает на Windows 10/11 без установки .NET — использует встроенный .NET Framework 4.8).

1. Запустить `MySwitcher.exe` откуда угодно (флешка, «Загрузки»).
2. На вопрос «Установить my-switcher на этот компьютер?» ответить **Да**.

Программа скопируется в `%LOCALAPPDATA%\Programs\MySwitcher`, появится в меню «Пуск» как *my-switcher*, пропишется в автозапуск и сразу запустится. Права администратора не нужны. Ответ **Нет** — просто запуск без установки.

Обновление — так же: закрыть программу (трей → Выход), запустить новый exe, ответить «Да».

Удаление — трей → **Удалить с компьютера…** (убирает автозапуск, ярлык и папку).

Windows SmartScreen может предупредить о неизвестном издателе (exe не подписан): «Подробнее» → «Выполнить в любом случае».

## Меню в трее

- **Включено** — временно отключить (или двойной клик по иконке; иконка станет серой).
- **Запускать при входе в Windows** — запись в `HKCU\...\CurrentVersion\Run`.
- **Удалить с компьютера…** — только у установленной копии.
- **Выход**.

## Ограничения

- Работает через буфер обмена (Ctrl+C → исправление → Ctrl+V), старое содержимое буфера потом возвращается.
- Нужно именно выделение. Некоторые редакторы (например, VS Code) без выделения копируют всю строку — тогда исправленная строка вставится в позицию курсора.
- В консоли Ctrl+C прерывает программу, там не использовать.
- Не работает в окнах, запущенных от администратора, если сам my-switcher запущен без прав администратора (ограничение Windows).

## Про «слежку за клавиатурой»

Программа ставит низкоуровневый хук клавиатуры (`DoubleShiftHook.cs`), иначе двойной Shift не поймать. Хук не запоминает, какие клавиши нажимались: он смотрит только на левый Shift, а любая другая клавиша лишь сбрасывает счётчик. Сетевого кода нет; на диск пишется только при установке/удалении (копия exe, ярлык, ключ автозапуска).

## Сборка

Нужен .NET SDK (собирается под .NET Framework 4.8).

```bash
dotnet build -c Release
```

Получится `bin\Release\net48\MySwitcher.exe` — это и есть весь дистрибутив (`.config` и `.pdb` рядом не нужны).

## Устройство

- `src/DoubleShiftHook.cs` — ловит двойной левый Shift (в отдельном потоке).
- `src/SelectionFixer.cs` — копирует выделение, исправляет, вставляет, возвращает буфер.
- `src/TextConverter.cs` — таблицы ЙЦУКЕН ↔ QWERTY и инверсия регистра.
- `src/Keyboard.cs` — синтетические нажатия и переключение раскладки.
- `src/TrayContext.cs` — иконка и меню в трее.
- `src/Installer.cs` — самоустановка, автозапуск, ярлык, удаление.
